# Quick Start Guide - AI PPT Maker & Resume Analyzer

## 🎯 What Was Built

### 1. AI PPT Maker (Like Gamma Tool)
Generate professional presentations from simple text prompts using AI.

**Example Usage**:
```
Topic: "Introduction to Machine Learning"
Slides: 7
Theme: Professional
→ Generates complete 7-slide presentation in 10-30 seconds
```

### 2. AI Resume Analyzer
Upload resume → Extract text with OCR → Analyze with AI → Get detailed insights.

**Example Usage**:
```
Upload: resume.pdf (or JPG/PNG)
→ OCR extracts text (5-10 seconds)
→ AI analyzes content (10-20 seconds)
→ Shows: Score, Strengths, Weaknesses, Suggestions, Skills, Recommendations
```

---

## 🚀 How to Use

### PPT Maker:
1. Go to PPT Maker page
2. Enter topic: "Your presentation topic"
3. Select slides: 5
4. Select theme: Professional
5. Click "Generate Presentation"
6. Wait 10-30 seconds
7. Navigate through slides
8. Download

### Resume Analyzer:
1. Go to Resume Analyzer page
2. Click upload area
3. Select resume (JPG/PNG/PDF, max 5MB)
4. Click "Analyze Resume"
5. Wait 15-30 seconds
6. View detailed analysis

## 🔧 Technical Details

### APIs Used:
1. **Gemini 2.5 Flash** - For PPT generation and resume analysis
2. **OCR.space** - For text extraction from resumes

### Edge Functions:
1. `gemini-ppt-generate` - Generates presentations
2. `ocr-extract` - Extracts text from images/PDFs
3. `resume-analyze` - Analyzes resume text
