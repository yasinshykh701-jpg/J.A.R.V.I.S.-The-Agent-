## 🚀 USAGE GUIDE

### Accessing Settings
1. Navigate to `/settings` or click "Settings" in sidebar
2. View AI Services tab for service status
3. View Data Management tab for data reset

### Using Free Services
```typescript
import { freeAiServices } from '@/services/freeAiServices';

// Text-to-Speech
await freeAiServices.tts.speak('Hello, world!');

// Speech-to-Text
const { stop } = freeAiServices.stt.listen((text) => {
  console.log(text);
});

// Image Generation
const imageUrl = await freeAiServices.imageGen.generateImage('A sunset');

// Chat
const response = await freeAiServices.chat.chat('Hello!');

// Video Generation
const videoUrl = await freeAiServices.videoGen.generateVideo('A robot');
```

### Clearing User Data
1. Go to Settings page (`/settings`)
2. Click "Data Management" tab
3. Click "Clear All User Data" button
4. Confirm the action
5. All user data will be deleted

### Resetting Application
1. Go to Settings page (`/settings`)
2. Click "Data Management" tab
3. Click "Reset Application" button
4. Confirm the action
5. App will reload with clean state
