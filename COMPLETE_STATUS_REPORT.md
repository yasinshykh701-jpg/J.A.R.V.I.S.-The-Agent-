## 🔧 Technical Stack

### Frontend
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **UI Library**: shadcn/ui
- **Styling**: Tailwind CSS
- **Routing**: React Router
- **State**: React Context + Hooks
- **3D**: React Three Fiber (Robot3D)
- **Icons**: Lucide React

### Backend
- **Platform**: Supabase
- **Database**: PostgreSQL
- **Authentication**: Supabase Auth
- **Storage**: Supabase Storage
- **Functions**: Edge Functions
- **Real-time**: Supabase Realtime

### AI APIs
- **Conversational AI**: DeepSeek API (deepseek-chat)
- **Image Generation**: Stable Diffusion (Replicate/Hugging Face)
- **Video Generation**: Kling AI (Luma/Replicate)
- **Voice Recognition**: Web Speech API
- **Text-to-Speech**: Device/System TTS API
